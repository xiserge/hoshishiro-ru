# Русский перевод «星空列车与白的旅行»

Неофициальный фанатский перевод визуальной новеллы **«星空列车与白的旅行»**
(Hoshizora Tetsudou to Shiro no Tabi / 星空鉄道とシロの旅, shiratamaco) на русский язык.

Переводятся диалоги, меню и кнопки. Работает офлайн, интернет не нужен.

## Скачать

Готовый архив — в разделе **[Releases](../../releases)**:
`星空列车与白的旅行-ru-1.0.zip`

## Установка

1. Закройте игру, если она запущена.
2. Распакуйте **всё содержимое архива** в папку с игрой — туда, где лежит
   `星空列车与白的旅行.exe` (например `...\Steam\steamapps\common\星空列车与白的旅行\`).
3. Запустите игру.

Первый запуск занимает 1–3 минуты (подготовка файлов), не закрывайте окно.

Подробнее — в `README.md` внутри архива.

## Удаление

Удалите из папки игры `BepInEx\`, `dotnet\`, `winhttp.dll`, `doorstop_config.ini`
и `.doorstop_version` (если появился). Игра вернётся к исходному состоянию.
